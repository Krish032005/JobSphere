Candidate can:

Register/login                                              Done
Create profile                                              DONE
Upload profile photo
Upload resume
Edit profile                                                DONE
Add skills, education, experience                           Done
Search jobs
Filter jobs
View job details
Apply for jobs
Save jobs
Track applications
See application status
Get AI resume analysis
Get resume improvement suggestions
Get recommended jobs/companies
Eventually get AI career recommendations


Recruiter can:

Register/login
Create company/recruiter profile
Create jobs
Edit/delete jobs
Publish/unpublish jobs
View applicants
View applicant profiles
Download/view resumes
Shortlist/reject candidates
Change application status
Use AI to rank applicants
See recruitment analytics
Eventually use paid recruiter features
